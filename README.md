# Sundown Studio Clone

A modern, highly interactive landing page clone of the award-winning **Sundown Studio** website, showcasing smooth animations, custom scrolling effects, and responsive design techniques.

👤 **Author:** H. Kumar ([@Git-H-kumar](https://github.com/Git-H-kumar) | [LinkedIn](https://www.linkedin.com/in/h-kumar-))

---

## Features

* **Smooth Scrolling:** Integrated using **Locomotive Scroll** for fluid page transitions and inertial scrolling.
* **Interactive Animations:** Complex UI interactions and hover effects powered by **GSAP (GreenSock Animation Platform)**.
* **Swiper Sliders:** Interactive touch-friendly carousels for project showcases.
* **Custom Cursor & Hover Effects:** Dynamic preview containers that track cursor movements across project lists.
* **Fully Responsive Design:** Optimized layout for mobile, tablet, and desktop screens.

---

## Tech Stack

* **Markup:** HTML5
* **Styling:** CSS3 (Flexbox, CSS Grid, Custom Media Queries)
* **Scripting:** JavaScript (ES6+)
* **Libraries & Frameworks:**
  * [Locomotive Scroll](https://github.com/locomotivemtl/locomotive-scroll)
  * [GSAP](https://greensock.com/gsap/)
  * [Swiper.js](https://swiperjs.com/)
